# Code of conduct

Moekura follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in the repository, its issues, pull requests and discussions,
and anywhere else you represent the project.

In short: be kind and welcoming, assume good faith, accept feedback
gracefully, and focus on what's best for the community. Harassment,
insults, sexualised comments or imagery aimed at people, and publishing
others' private information are not accepted.

## Reporting

Report unacceptable behaviour to the maintainers at
[hello@uwuu.moe](mailto:hello@uwuu.moe). Every report is reviewed and
kept confidential. The maintainers decide on the consequences, following
the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines),
from a warning up to a permanent ban.
